# HoldGrip

ابزار اندرویدی اجرای ژست لمس پیوسته: با نگه‌داشتن دکمه شناور، انگشت مجازی از نقطه A به B حرکت می‌کند و تا زمان رها کردن دکمه در نقطه B باقی می‌ماند.

## قابلیت‌های نسخه 1.3

- حفظ هسته اجرای ژست پیوسته و چرخه رهاسازی مبتنی بر `HoldChain`.
- نمایش وضعیت دکمه هنگام نگه‌داشتن، درخواست رهاسازی و پایان ژست.
- ساخت و مدیریت چند پروفایل ژست با نام دلخواه.
- هر پروفایل مختصات شروع و پایان و مدت حرکت مخصوص خودش را دارد.
- جابه‌جایی بین پروفایل‌ها بدون تنظیم مجدد نقاط.
- تغییر نام و حذف پروفایل؛ همیشه دست‌کم یک پروفایل باقی می‌ماند.
- خروجی پشتیبان از همه پروفایل‌ها و تنظیمات دکمه شناور و بازیابی آن روی دستگاه دیگر.
- تنظیم اندازه و شفافیت دکمه، قفل جابه‌جایی و نمایش/مخفی‌کردن آن.
- نگهداری تنظیمات نسخه‌های قبلی هنگام اولین ارتقا؛ پروفایل اصلی از مقادیر فعلی دستگاه ساخته می‌شود.

## ساخت APK با GitHub Actions

1. شاخه `upgrade/pro-suite` را باز کن.
2. وارد بخش **Actions** شو و آخرین اجرای **Build APK** را انتخاب کن.
3. بعد از موفق شدن مراحل تست و ساخت، در بخش **Artifacts** فایل `HoldGrip-apk` را دانلود کن.
4. ZIP را باز کن و فایل `app-debug.apk` را نصب کن.

نسخه برنامه به 1.3 و شماره ساخت به 4 افزایش یافته است. شناسه بسته همچنان `com.holdgrip` است. گردش ساخت از کلید امضای Debug ذخیره‌شده در GitHub Actions استفاده می‌کند تا ساخت‌های بعدی همان امضا را داشته باشند. نصب به‌روزرسانی فقط زمانی بدون حذف نسخه قبلی ممکن است که APK نصب‌شده قبلی نیز با همین کلید امضا شده باشد؛ اگر نسخه قبلی با کلید دیگری ساخته شده باشد، اندروید اجازه نصب روی آن را نمی‌دهد.

## استفاده از پروفایل‌ها و پشتیبان

- از بخش «پروفایل‌های ژست» یک پروفایل جدید بساز؛ تنظیمات فعلی به عنوان نقطه شروع آن کپی می‌شوند.
- برای هر پروفایل، از «تنظیم نقاط و دکمه» مختصات دلخواه را ثبت کن.
- از بخش «پشتیبان‌گیری و انتقال» یک فایل `.hgp` بساز.
- روی دستگاه دیگر HoldGrip را نصب کن و همان فایل را از گزینه بازیابی انتخاب کن. بازیابی، پروفایل‌ها و تنظیمات موجود را جایگزین می‌کند.

## مجوز لازم

برای اجرای ژست، سرویس دسترس‌پذیری Android باید از تنظیمات گوشی فعال باشد. این مجوز به HoldGrip امکان می‌دهد ژست لمسی را روی برنامه‌های دیگر اجرا کند.
