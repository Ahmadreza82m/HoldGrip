# HoldGrip

اپ اندروید ساده: یک دکمه شناور که با نگه داشتنش، یک ژست پیوسته از نقطه شروع به نقطه پایان می‌کشد و تا رها کردن دکمه همان‌جا نگه می‌دارد.

## ساخت APK با گیت‌هاب
1. یک repository جدید بساز و همه فایل‌های این پوشه را در آن آپلود کن.
2. اگر پوشه `.github` آپلود نشد (فایل‌های مخفی گاهی نمی‌روند)، در گیت‌هاب Add file ← Create new file بزن، به عنوان نام فایل `.github/workflows/build.yml` را بنویس و محتوای فایل `build.yml` همین پروژه را داخلش بچسبان.
3. به تب Actions برو، workflow به نام Build APK خودکار اجرا می‌شود (یا Run workflow بزن).
4. بعد از تمام شدن، پایین صفحه همان اجرا در بخش Artifacts فایل `HoldGrip-apk` را دانلود کن.
5. زیپ را باز کن و `app-debug.apk` را روی گوشی نصب کن.

## استفاده
1. اپ را باز کن و «فعال‌سازی سرویس دسترسی» را بزن. HoldGrip را روشن کن.
2. «تنظیم نقاط و دکمه» را بزن. ۴ ثانیه وقت داری بازی را باز کنی، بعد سه دایره می‌آید: سبز = شروع، قرمز = پایان، بنفش = جای دکمه. بکش و «ذخیره» را بزن.
3. دکمه شناور را نگه دار. تا وقتی نگه داشته‌ای، انگشت مجازی روی نقطه پایان می‌ماند.
4. اگر کشیدن کند است، «مدت کشیدن» را کمتر کن (مثلاً ۷۰).
